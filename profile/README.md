# Project Overview

Plex is a media platform that combines personal media management with playback across computers, mobile devices, smart TVs, streaming devices, and web browsers.

With Plex Media Server, users can organize their own movies, TV shows, music, photos, and home videos into searchable libraries. Plex automatically catalogs supported media and can add artwork and metadata.

The platform also provides dedicated player applications and a web interface for accessing available content.

---

# Plex Media Server

Plex Media Server is the central component for managing a personal media collection.

The server can run on Windows, macOS, Linux, compatible NAS devices, and NVIDIA SHIELD. It manages media libraries and makes supported content available to authorized Plex clients.

Unlike a conventional desktop application, Plex Media Server does not use a separate graphical server window. Server management is performed through the Plex Web App.

---

# Movies, TV Shows & Music

Plex can organize different types of personal media into dedicated libraries.

Supported library types include:

* Movies
* TV shows
* Music
* Photos
* Home videos

Plex can automatically catalog media and retrieve associated artwork and information, creating a centralized interface for browsing a collection.

---

# Playback & Transcoding

Plex clients can play compatible media directly when the playback device supports the source format.

When direct playback is not possible, Plex Media Server can transcode media into a format better suited to the client device or network connection.

Transcoding requirements depend heavily on the source format, target device, resolution, subtitles, number of simultaneous users, and whether hardware acceleration is available. Plex notes that insufficient server CPU resources can result in buffering or playback problems during transcoding.

---

# Desktop Apps & Offline Downloads

Plex provides dedicated applications for Windows, macOS, and Linux.

The Windows and Mac desktop applications provide a standalone interface with enhanced playback capabilities and support for downloading personal media for offline use when the applicable Plex Pass requirements are met.

Plex Downloads can also be used on supported mobile and desktop applications for offline access to personal media.

# System Compatibility & Performance

| Component        | Minimum Practical Configuration                |
| ---------------- | ---------------------------------------------- |
| Operating System | Windows 10 64-bit or later for Plex desktop    |
| Processor        | Modern dual-core CPU                           |
| Memory           | 2 GB RAM minimum; 4 GB+ recommended            |
| Storage          | 200 MB+ for application/server files           |
| Graphics         | Integrated graphics supported                  |
| Display          | 1024×768 or higher                             |
| Architecture     | x64 for current Windows desktop app            |
| Network          | Recommended for streaming between devices      |
| Media Storage    | Additional storage required for personal media |

Plex for Windows requires **Windows 10 or later and 64-bit architecture**.

Plex Media Server has separate requirements depending on the operating system or NAS platform. On Windows, Plex Media Server supports Windows 10 version 1607 or newer and x86/x64 processors; ARM-based Windows systems are not currently supported for Plex Media Server.
